# Splash artwork

`astronaut.png` is the 200 × 200 RGBA splash image supplied by SOLOMINER and
included under GPL-3.0-only. Its transparent pixels preserve the starfield.
See [asset sources](../../docs/ASSET_PROVENANCE.md).

`python scripts/generate_artwork.py --check` verifies its generated LVGL array.
The legacy `Astronaut_200x200` symbol is retained for firmware compatibility.
